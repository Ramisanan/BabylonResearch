# Babylon Research

This repository contains the data analysis and supporting materials for a study of ancient Babylonian commodity prices.

The project compares two price representations:

* \(x\): quantity per shekel
* \(1/x\): price per unit

The main analyses include:

* Benford's first-digit law
* Z-score normalized price distributions
* Stretched-exponential fitting
* DFA-2 at monthly and annual scales

The study focuses on six commodities: barley, dates, sesame, cress, mustard, and wool.
